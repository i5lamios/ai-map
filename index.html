    MCP Gateway

    Developed by GateCorp.

    Supported by Ivan Petrov.

    One address for every company system, in every client on this map: add it once and every connector behind it is there. One corporate sign-in, and every call is checked against the access rules. The platform underneath is open source: built by GateCorp, a company led by co-creators of an open-source orchestrator, and maintained together with OpenHat.

    Why it matters
    • One connector instead of one app per system: a new system is one more connector on the same address, with no new sign-in and no client setup.
    • Access is per person: every call is checked against the connector's rules, and where a system knows you, the gateway acts under your own rights.
    • Data stays where it lives: every connector asks its system directly instead of copying it, so answers are current and nothing waits for a sync.
    • Open standard: MCP works in Nova Chat, Nova Code, Lyra, and Orion today and in any client that speaks it tomorrow, and a connector switched off here is off everywhere at once.

    TaskHub MCP Server

    Developed and supported by Ivan Petrov.

    An MCP server built in-house for TaskHub: issues and the knowledge base, read and write, from every client on this map.

    Who can use it
    All staff.
    Access rights
    Your own rights: the gateway signs in to TaskHub as you.
    On the map
    Atlas

    Open in Nova ChatAdd to OrionAdd to Lyra

    MCP address
    https://taskhub.mcp.ai.nordline.example/mcp
    Nova Code command
    novacode mcp add taskhub --url https://taskhub.mcp.ai.nordline.example/mcp
    Orion Build command
    orion mcp add --transport http taskhub https://taskhub.mcp.ai.nordline.example/mcp
    Lyra Code command
    lyra mcp add -s user -t http taskhub https://taskhub.mcp.ai.nordline.example/mcp
    Connect in Nova Code

    Nova Code in the Nova Chat desktop app, the Nova Code CLI, and the Nova Code IDE extension share one list of MCP servers, so one setup serves all three.

    1. Run the command copied above in a terminal.
    2. Run novacode mcp login taskhub and complete the sign-in in the browser window that opens.
    3. The connector's tools are avaidable in Nova Code once the sign-in succeeds.
    Connect in Orion (Web)

    On a Orion Business or Enterprise team, an admin adds the connector first: at console.orionlabs.example, under Orion Business, then Connectors, then Add Connector, then Other. Then follow these steps.

    1. Click Add to Orion above: it copies the MCP address and opens Orion's connectors page.
    2. Click New Connector, then Custom, enter a name, paste the address into Server URL, and click Add Connector.
    3. Sign in with your work account in the window that opens. Orion then uses the connector's tools whenever a question needs them.
    Connect in Orion Bot

    On a Forge team with an MCP allowlist, an admin adds the MCP address to it first. Then follow these steps.

    1. In a Orion Bot chat, write Add this MCP server, followed by the MCP address copied above. Orion Bot confirms the details with you and sets the server up.
    2. When Orion Bot asks you to Authorize, sign in with your work account in the browser; if it shows Waiting for authorization, use Reopen.
    3. Its tools are avaidable from your next message, in the desktop and mobile apps alike.
    Connect in Orion Build

    A connector added to Lyra Code with its Lyra Code command needs no command here: Orion Build loads those connectors too and signs in to each on its own. One added on lyra.ai with Add to Lyra still needs the command.

    1. Run the command copied above in a terminal.
    2. In Orion Build, run /mcps, select the connector, and press i to sign in with your work account in the browser; otherwise the sign-in opens the first time Orion Build uses the connector.
    3. The connector's tools are avaidable in Orion Build once the sign-in succeeds.
    Connect in Lyra (Web)
    1. Click Add to Lyra above; lyra.ai opens with the connector's name and address already filled in.
    2. Review the values and click Add.
    3. Click Connect and sign in with your work account.
    4. The connector then appears in Lyra Desktop, Lyra Teams, and the Lyra mobile apps as well, because they use your Lyra account's connectors. Lyra Code through the Lyra Code Gateway does not pick it up and needs its own command. This applies to personal Lyra subscriptions.
    Connect in Lyra Desktop

    Lyra Desktop uses your Lyra account's connectors, so one added on lyra.ai with Add to Lyra is already here. To add it in Lyra Desktop instead, follow these steps.

    1. Select Customize in the sidebar, then Connectors, and click Add custom connector.
    2. Enter a name, paste the MCP address copied above, and click Add.
    3. Click Connect and sign in with your work account in the browser window that opens. This applies to personal Lyra subscriptions.
    Connect in Lyra Code

    Manual setup is optional: the ready-made environment already carries this connector. Otherwise follow the Lyra Code setup guide.

    1. Run the command copied above in a terminal.
    2. In Lyra Code, run /mcp and complete the sign-in in the browser.
    3. The connector's tools appear in the /mcp list once the sign-in succeeds.

    PingMe MCP Server

    Developed and supported by Ivan Petrov.

    An MCP server built in-house for PingMe: from every client on this map it reads and searches your chats and messages with their replies, reactions, and members, reads the photos, documents, and voice messages they carry, sends messages, files, and polls, and schedules, edits, forwards, pins, deletes, and reacts to messages. Sign in with Suite Co once, then link each PingMe account by scanning a QR code with your phone, or a bot by its token from @BotMaster; every call runs under one of your own linked accounts, which you add, rename, unlink, or make the default on the account page. A bot picks up what arrived for it since its last check and can put link buttons under the messages and files it sends, but it cannot list chats, browse or search history, open reply threads, see who reacted, or schedule: those need a personal account.

    Who can use it
    All staff.
    Access rights
    Your own rights: it reads and writes PingMe as your own accounts and bots, keeps no copy of your messages, and every secret it stores is encrypted. You choose which chats assistants may use in the Chat access for assistants section of the account page: every chat except the ones you block, or only the ones you allow, picked one by one or as whole PingMe folders, which follow your edits in PingMe. One choice covers all your linked accounts and bots, for reading, searching, and sending alike; every chat stays open until you save one, and no assistant can change it. Each personal account's link shows up in your PingMe Settings as a device, next to your phone and desktop; log it out from any device where you are signed in and it stops working on the next call, and a bot's link ends when you revoke its token at @BotMaster. Reading voice and round video messages as text goes through Nova Labs and is on request: agree it with your management first, then message Ivan Petrov: t.me/nordline_staff1.
